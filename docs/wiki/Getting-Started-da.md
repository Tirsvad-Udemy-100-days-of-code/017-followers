# Kom godt i gang

## Krav

Python 3. Der er ingen afhængigheder ved kørsel.

## Opsætning

```bash
git clone https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/017-followers.git
cd 017-followers
```

## Kør

```bash
python src/main.py
```

## Tests

```bash
python -m py_compile src/main.py
```
